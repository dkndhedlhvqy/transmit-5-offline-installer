## About

Transmit 5 is a premium macOS file transfer application from Panic for FTP, SFTP, WebDAV, Amazon S3, Backblaze B2, and other cloud services. Features a dual-pane browser, Panic Sync for server list synchronization, batch operations, server-to-server transfers, and Automator actions. Transmit's polish and performance make it the go-to file transfer tool for professional Mac users.

## Common Problems & Limitations

- **macOS Only** — No Windows or Linux version
- **Commercial License** — Paid one-time purchase
- **Cloud Breadth** — Supports key cloud services; some niche providers not covered
- **iOS Version Separate** — Transmit for iOS sold separately
